# 🐾 貓咪邏輯謎題

純前端的貓咪邏輯謎題，零依賴、可離線、手機優先。
玩法致敬 Oakever Games 的 **Meowdoku**（本專案為自行實作，未使用其程式或素材）。

> 原本的養貓／學院／換裝等養成系統已獨立成另一個遊戲 **貓咪夢工廠**（`catmaker`）。

## 邏輯謎題規則

1. 棋盤切成 N 個連通色塊，**每個色塊恰好 1 隻貓**
2. **每一列、每一行恰好 1 隻貓**
3. **兩隻貓不能相鄰**（含斜角）
4. 每一題都是**唯一解**，而且**純靠邏輯推導就能解完，不需要猜**
5. **不會太簡單**：沒有 1 格的色塊（等於白送一隻貓），也不會只靠「這裡只剩一格」就能一路解完

## 操作

| 動作 | 效果 |
|---|---|
| 點格子 | 依目前模式動作（`✕ 排除` 打叉／`🐱 放貓`） |
| 再點同一格 | 取消該記號 |
| 長按（手機）／右鍵（桌機） | 清除該格 |
| 鍵盤 | `方向鍵` 移動、`X` 打叉、`C` 放貓、`Backspace` 清除、`H` 提示 |

放貓時若違反規則會扣 1 條小魚乾（共 3 條）；小魚乾用完就結束這一局。

## 功能

- 四種難度：**5×5 簡單、7×7 普通、9×9 困難、🔥 專家**
- **🔥 專家**：9×9，只收解題時至少要卡住 3 次、靠「色塊只落在同一列／行 → 排除那條線」才能往下的題目（`engine.js` 的 `eliminationSteps`，約前 35% 難的）；沒有自動打叉與提示，最佳時間另外記。挑一題約 1～10 秒，所以開站就在背景先備好一題
- **每日挑戰**：以日期為亂數種子，同一天所有人拿到同一題；完成會記錄連續天數
- **自動打叉**（可關）：放貓後自動把同列、同行、同色塊與周圍 8 格打叉
- **提示**：用純邏輯推理找出「色塊／列／行只剩一個位置」的下一步
- 復原、重來、計時、各尺寸最佳時間（存本機）
- 深色／淺色主題；PWA 可加到主畫面、離線可玩
- **配樂**：`audio.js` 用 Web Audio 即時合成（沒有音檔）；5×5／7×7／9×9／每日挑戰各有兩首，由題目決定播哪首（`js/meowdoku.js` 的 `MUSIC`）
- **特效**：放貓時貓會彈一下、同列／行／色塊由近到遠亮起；過關時貓咪輪流跳、撒彩紙再跳出結算（系統設定「減少動態」時關閉）
- 進度自動存在本機，重新整理會接續同一局

## 題目怎麼來的（重點）

隨機切色塊幾乎不可能得到唯一解（實測 n=7、9 都是 0/30），所以 `engine.js` 用**建構式**生成：

1. 先取一個合法解答（排列且相鄰兩列欄位差 ≥ 2）
2. 列出**所有**其他合法擺法（n=9 有 5242 種；A002464 數列）
3. 逐一指派格子到相鄰色塊，**每一格都必須維持「唯一解」**（某色塊內出現 2 隻貓的擺法即被排除）
4. 全部格子指派完後，再用**精確解題器**複驗「解數 = 1」，並用**純邏輯解題器**確認不用猜

因此每一題都同時滿足「唯一解」與「純邏輯可解」，這兩點由程式保證，不是靠運氣。

## 開發與測試

```bash
# 核心驗證（解的合法性、色塊連通、解題器與暴力解交叉比對、生成品質與效能）
node tests/engine.test.mjs 40

# 本機開遊戲（Service Worker 需要 http/https）
python3 -m http.server 8120
# 開 http://127.0.0.1:8120/
```

`tests/engine.test.mjs` 的檢查項目：

- 精確解題器與**暴力解**逐盤交叉比對（避免解題器寫錯卻悄悄放行）
- 合法解、色塊覆蓋與連通性
- 生成品質：唯一解率、純邏輯可解率、耗時（實測平均 5×5 約 1ms、7×7 約 15ms、9×9 約 0.7 秒，背景執行緒預先生成下一題）

## 檔案結構

```
index.html              # 畫面骨架
style.css               # 樣式
audio.js                # 音效與背景音樂（Web Audio 即時合成）
engine.js               # 謎題生成器／解題器（純函式，瀏覽器與 Node 共用）
gen-worker.js           # 背景執行緒生成謎題
js/main.js              # 進入點：全域按鈕、啟動
js/ui.js                # 共用：DOM、儲存鍵、底部面板、提示音
js/meowdoku.js          # 邏輯謎題畫面與操作、換貓圖示
icons/                  # 圖示、貓臉 sprite（cats.webp）
sw.js                   # Service Worker（離線快取）
manifest.webmanifest    # PWA
tests/engine.test.mjs   # 生成器／解題器驗證
```
